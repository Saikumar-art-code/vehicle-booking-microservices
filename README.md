# Vehicle Booking Microservices

A microservices-based vehicle booking system with wallet and payment flow.

## Services
- Auth Service: Rider login, wallet top-up
- Booking Service: Vehicle booking and rental logic
- Wallet Service: Wallet deduction and transactions

## Frontend
Simple UI to test booking and payment flows.

## Tech Stack
- Node.js
- Express.js
- MongoDB
- Plain HTML + JavaScript
